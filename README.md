# Appli agences – Diag Pro Eco

Demande de devis de diagnostics immobiliers pour les agences, et vérification de la validité des diagnostics existants.

- Adresse : https://diagproeco.github.io/agences/
- Lien direct pour installer l'appli (à envoyer) : https://diagproeco.github.io/agences/installer (page `installer.html` : installation en un geste quand le navigateur le permet, sinon les gestes pour le téléphone utilisé ; bouton pour quitter Messenger, Facebook… d'abord).
- Les adresses se complètent grâce au service gratuit de géocodage de l'IGN (Géoplateforme).
- Les demandes partent par mail à diagproeco@gmail.com via un petit relais Google Apps Script.
- Règles des diagnostics : `regles.js` (vérifiées le 22/11/2026, sources en bas du fichier).
